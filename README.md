# SQL Business Analysis

**Exploring Socioeconomic Data with SQL and SQLite**

## About the Project

This portfolio project explores socioeconomic data through SQL queries, analytical questions, and data interpretation.

Using the Gapminder dataset, the project investigates relationships and patterns across countries, focusing on indicators such as GDP per capita and years of education.

## Objectives

- Develop practical SQL skills using SQLite.
- Explore socioeconomic indicators through analytical questions.
- Practice data aggregation, filtering, and table joins.
- Translate query results into meaningful interpretations.
- Demonstrate SQL applications in business and data analysis.

## Dataset

The project uses the Gapminder dataset studied during SQL training at Fundação Getulio Vargas (FGV).

The database includes tables related to:

- Countries
- GDP per capita
- Years of schooling among women
- Years of schooling among men

Original data sources and applicable usage licenses will be documented alongside the dataset.

## Tools & Technologies

- SQL
- SQLite
- DBeaver
- GitHub

## Analytical Approach

Each investigation follows four steps:

1. **Business Question:** Define the analytical question.
2. **SQL Query:** Develop the query to investigate the data.
3. **Results:** Present the query output.
4. **Analysis:** Interpret the findings and their implications.

## Repository Structure

The project will be organized into SQL queries, analytical questions, results, and supporting documentation.
