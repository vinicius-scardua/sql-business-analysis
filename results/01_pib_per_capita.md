# Análise 01 — Países com maior PIB per capita em 2025

## Pergunta de negócio

Quais países apresentam os maiores valores de PIB per capita em 2025?

## Objetivo

Identificar os dez países com os maiores valores de PIB per capita no ano selecionado, utilizando filtros e ordenação em SQL.

## Resultado

| País | PIB per capita (US$) |
|---|---:|
| Monaco | 226.000 |
| Ireland | 119.000 |
| Luxembourg | 113.000 |
| Singapore | 113.000 |
| Qatar | 102.000 |
| UAE | 78.700 |
| Switzerland | 72.100 |
| Norway | 69.600 |
| USA | 67.300 |
| San Marino | 67.100 |

## Interpretação

Monaco apresentou o maior PIB per capita entre os países retornados, com US$ 226 mil. Ireland ocupou a segunda posição, com US$ 119 mil.

A diferença entre os dois primeiros colocados foi de US$ 107 mil por habitante.

O resultado permite comparar o indicador entre países, mas não representa diretamente a renda individual ou a distribuição de riqueza da população.

## Recursos SQL utilizados

- SELECT
- WHERE
- ORDER BY DESC
- LIMIT

## Período analisado

Ano de referência: 2025.
